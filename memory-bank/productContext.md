# Product Context

## Why BizBrain Exists
Small to medium businesses need an affordable, reliable ERP that works even without internet connectivity. Many businesses in developing regions face intermittent connectivity.

## Problems It Solves
- Offline data access and entry (IndexedDB)
- Business registration with multi-step wizard
- Invoice/project/expense tracking
- Data sync when connectivity is restored
- PWA installable on mobile devices

## UX Goals
- SaaS-grade polished UI with glassmorphism
- Intuitive multi-step registration
- Real-time validation with async availability checks
- Dark/light mode support
- Responsive for desktop and mobile
